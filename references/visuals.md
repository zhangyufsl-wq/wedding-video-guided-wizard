# 分镜、外部生图和图生视频

## 第 6 步

每镜记录 id、事实来源、对应旁白、成片区间、人物时期、地点、画风、首帧、核心动作、尾帧、衔接和返回检查点。时间来自已确认实际旁白，也包含情绪留白；源视频长度不等于最终使用长度。每镜一个叙事任务，允许简单辅助动作，少做多次手部交接、复杂旋转或多人调度。难事件用拆镜/换景别降低难度，不删改事实。

画风服从本单采集卡；动画区分真人脸＋动画环境和全动画人物。把参考风格转成光线、色彩、材质、景深等可执行要求，不依赖别的私有 Skill，不把所有订单固定为校园日系。共用画风并不意味着同一景别、同一光线。

人物身份来自本人照片。明确两人各对应哪张参考，合照清楚时可标注；容易混淆或不清晰时请补单人照，不能靠描述猜脸。确认年龄阶段、服装与重要道具。每个真人镜头都必须提供对应人物参考。

## 第 7 步：角色定妆

画风先写进项目根目录的 `STYLE.md`（从 [style-qban.md](../assets/style-qban.md) 复制后按本单改），每条生图提示词开头原样引用，不在各镜重写外貌。只锁 3–5 个关键特征：发型发色、脸型比例、标志物（眼镜、痣）、主服装、配色。

每位人物用 1–3 张清晰正脸/半身照生成一张 Q 版设定图（正面、侧面、全身）：

```bash
python3 scripts/ark.py character PROJECT --name '新郎 阿杰' --photos photos/groom-1.jpg photos/groom-2.jpg --style STYLE.md --out characters/groom-v1.png --authorized
```

不像就换照片或改 STYLE.md 再出 v2，不在后续镜头里补救。确认后写 `CHARACTERS.json`：

```json
{"style":"STYLE.md","characters":[
  {"id":"groom","name":"新郎 阿杰","sheet":"characters/groom-v1.png"},
  {"id":"bride","name":"新娘 小雨","sheet":"characters/bride-v2.png"}]}
```

再选约三个高风险镜头（双人同框、时期变化、手与道具、关键情绪）试图。第 7 步 `prepare` 登记 CHARACTERS.json、全部设定图和试图。之后的镜头只用设定图做参考，真人原图不再进入生成流程。

## 第 7–8 步：分镜首帧

```bash
python3 scripts/ark.py keyframe PROJECT --shot S04 --prompt prompts/S04-image.txt --refs groom bride --out images/S04-v1.png --ratio 16:9 --authorized
```

提示词只写这一镜：场景、光线、两人位置、手里已有物品、表情、构图、动作空间。工具自动在前面拼接 STYLE.md 和「第 1 张参考图是…」映射。第 8 步会校验角色表与设定图都是第 7 步确认版本，改过就拒绝。

未配置 `ARK_API_KEY` 或制作方未授权付费时，交同样内容的手动包（参考图顺序＋完整提示词），等实际文件回传。

收到实际图逐镜检查：像设定图、同一对人、时期、画风、手与物、乱码/多余人物、动作空间、相邻场景一致性。整套检查含试图。选中版本及指纹登记，换图重查。

## 第 9 步

先看选中首帧，再列「实际起点→核心动作→结束状态」。已经抬头不倒退重演抬头，已经走近不重新从远处开始。首帧与关键情节冲突时，先提出局部修图/改分镜并确认，不指望视频词凭空修复。

每条视频词自含：明确来源图、时长画幅、连续动作和节奏、一个主要运镜、身份/服装/道具/场景保持项。一般一镜到底，无对白无配乐；有本单明确需要才例外。不重写外貌，位置可随动作改变，不同时要求走近与站位固定。

已授权时用 `ark.py i2v-batch PROJECT --max-shots N --authorized` 按确认分镜顺序逐镜生成，失败即停，超时留 `.pending.json` 用 `ark.py fetch` 续取；建议先 `--max-shots 1` 跑最难一镜。无论 API 还是手动，交付逐镜包：每镜一个目录，实际选中首帧图片＋视频提示词；根目录有使用说明和指纹清单。用 `wizard.py video-pack` 创建，禁止空壳路径包。模型需支持首帧，普通参考槽不自动等同首帧锁定。

手动说明：上传对应首帧→复制本镜视频词→设置时长画幅→生成→自查→按镜号发回。可以在本步建议先生成最难一镜减少浪费，不新增固定编号。有已配置可用且授权的视频 API 可当前对话执行。

返回后看完整动作与相邻剪点：核心情节是否成立、脸手物是否稳定、是否突然切镜或生成人声、动作有没有倒退。文案说到的关键动作没有发生时，局部重做或调整并重新确认；接受局部例外必须记录具体位置与制作方决定。解码通过不能替代观看，图片通过不能代替视频通过。
